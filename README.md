# gorev_takip_sistemi
Temel Python konseptlerini (fonksiyonlar, listeler, döngüler) içeren Terminal tabanlı görev takip uygulaması.

## 📌 Özellikler
- **Görev Ekleme:** Yeni görevleri anında yapılacaklar listesine dahil eder.
- **Listeleme:** Aktif görevleri indeks numaralarıyla düzenli biçimde sıralar.
- **Görev Tamamlama:** Tamamlanan görevleri listeden çıkarıp arşiv alanına aktarır.
- **Hata Yönetimi:** Geçersiz girdi durumlarında programın çökmesini engeller.
